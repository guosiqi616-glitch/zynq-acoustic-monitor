# 系统组成与使用说明

> 2026-11-03　基于当前实际代码整理，不含未实现的功能。

---

## 一、一句话概括

一块 Zynq-7010 开发板 + 一个音频编解码模块 + 一个温湿度传感器 + 一台电脑，
用 FPGA 做实时声学特征提取，用 ARM 做统计判决，用浏览器做可视化。

---

## 二、硬件用了什么

| 器件 | 型号 / 参数 | 作用 | 接口 |
|---|---|---|---|
| 开发板 | 正点原子 领航者 ATK-DP7101，XC7Z010 | 双核 Cortex-A9 + 可编程逻辑 | — |
| 音频编解码 | ES8388 | 模拟声音 → 48 kHz/16 bit 数字流 | I2S（bclk/lrclk/sdata） |
| 温湿度传感器 | SHT30 | 环境温度、湿度 | I2C0，地址 0x44 |
| USB 串口 | CH340（板载） | 板子与 PC 通信 | UART 115200 8N1 |
| 音频输入 | 麦克风（经放大模块）+ 3.5 mm 线路输入 | 采集现场声音，或接入标准信号源 | 模拟（两路均可用） |
| 电源 | DC 5 V | 供电 | — |

**说明**：系统提供两路音频输入——**麦克风（经放大模块）**与**线路输入**，两路均可用。
抗噪声实验与日常测试使用线路输入，因为素材可重复播放、便于定量对比；现场部署时直接接麦克风即可。

## 三、PL（FPGA）里有什么

### 3.1 数据通路上的模块

| 模块 | 行数 | 作用 |
|---|---|---|

| `i2c_dri.v` / `i2c_reg_cfg.v` | 516 / 194 | 上电配置 ES8388 的寄存器 |

`audio_config.v`、`audio_ctrl.v`、`audio_send.v`、`slave_signal_gen.v` —— 音频回环与信号发生器，用于最初验证 I2S，现在不参与监测。

| 项 | 值 |

## 四、PS（ARM）里有什么

| 文件 | 行数 | 作用 |
|---|---|---|
| `helloworld.c` | 552 | 初始化、I2C/SHT30、50 Hz 主循环、协议组帧、事件状态机 |
| `detector.h` | 424 | **核心**：多维判决（动态基线、卡方、语音抑制） |
| `platform.c/h` | 111 / 41 | 板级初始化 |

### 4.1 PS 每个 20 ms 做什么

1. 从 AXI GPIO 读两路能量 + 事件状态字
2. `det_feed()`：更新噪声底、算 BER、更新动态基线、算卡方分数、分级
3. 事件状态机：开闸延时 500 ms、冷却窗 1.5 s、发 E 帧
4. 每 5 秒读一次 SHT30，做温度融合
5. 组帧发送：T 帧 50 Hz、X 帧 10 Hz、S/I 帧 1 Hz

### 4.2 判决用到的参数

| 参数 | 值 | 含义 |
|---|---|---|
| 判决模型 | 2 自由度卡方 | 谱形 z 分数 + 峭度 z 分数 |
| L1 阈值 | χ²(2,0.01)=9.210 | 关注 |
| L2 阈值 | χ²(2,0.001)=13.816 | 告警 |
| 基线时间常数 | 30 s | 门控 EWMA |
| 门控 | 2.5σ | 偏离超过就不学 |
| 语音判据 | BER 低于基线 440 ms | 判为语音，不报警 |
| 绝对门限 | 能量 3000 | 低于此不判 |
| 温度融合 | 高于基线 3 ℃ | 配合声学异常升到 L3 |

## 六、数据怎么流动

```
声音 → ES8388 → I2S → PL 滤波/能量/BER → AXI GPIO → PS 判决
                                                        ↓
                                             UART 文本帧（50 Hz）
                                                        ↓
                                    Python 桥接（解析/统计）
                                                        ↓
                                    WebSocket → 浏览器渲染
```

### 协议帧（v1.1）

| 帧 | 频率 | 内容 |
|---|---|---|
| `I` | 1 Hz | 设备信息、协议版本、采样率、窗长 |
| `T` | 50 Hz | 序号、时间、温湿度、两路 dB、BER、状态、事件计数 |
| `S` | 1 Hz | 状态标志、错误计数 |
| `E` | 事件触发 | 事件：dB、BER、阈值、原因 |
| `X` | 10 Hz | 诊断：级别、判决分、基线 μ/σ、噪声底、峭度、标志位 |

## 七、现在怎么用

### 7.1 启动（三步）

```powershell
# ① 板子上电 + USB 线

# ② 烧写（约 20 秒）
D:\Xilinx\Vitis\2020.2\bin\xsct.bat D:\Xilinx\S\project\project_1\run_board.tcl

# ③ 起服务
cd /d D:\Xilinx\S\project\project_1\host_software
..\.venv\Scripts\python.exe relay\server.py --source serial:COM5@115200 --port 8080 --mode board
```

或者直接双击 `D:\Xilinx\S\project\project_1\启动演示.bat`，会自动找串口、烧写、起服务、开浏览器。

浏览器：`http://127.0.0.1:8080/dashboard.html`（Ctrl+Shift+R 强刷）

### 7.2 演示

```
test_audio\DEMO_20261103\播放.ps1
```

### 7.3 复现抗噪声实验

```powershell
cd D:\Xilinx\S\project\project_1\host_software
..\.venv\Scripts\python.exe tools\make_stimuli.py
..\.venv\Scripts\python.exe tools\run_experiment.py --port COM5 --out ..\records\exp_run.csv
..\.venv\Scripts\python.exe tools\analyze_experiment.py --csv ..\records\exp_run.csv
```

# 抗噪声对比实验报告

> 对象：基于 Zynq-7000 的机械异响在线监测系统（XC7Z010）
> 日期：2026-11-02
> 数据：`records/exp_run2.csv`（原始串口日志）、`records/exp_results.csv`（汇总）
> 复现脚本：`host_software/tools/make_stimuli.py` / `run_experiment.py` / `analyze_experiment.py`

## 1. 实验目的

创新点二的核心主张是"动态背景基线 + 多维判决比固定阈值更能抵抗环境噪声"。
这句话必须用数据支撑，否则只是一个设计声明。本实验回答三个问题：

1. 固定能量阈值在背景噪声升高时会发生什么？
2. 固定频带能量比（BER）阈值在高频噪声环境下会发生什么？
3. 多维判决在这些条件下是否还能同时保持高检出率和低误报？

## 2. 实验设计

### 2.1 平台与信号链

| 项目 | 配置 |
|---|---|
| 硬件 | 正点原子领航者 ZYNQ-7010（XC7Z010） |
| 工具链 | Vivado 2020.2 / Vitis 2020.2 |
| 音频输入 | PC 线路输出 → 板载 ES8388 LINE IN（48 kHz / 16 bit） |
| PL 处理 | 双带 31 阶 FIR（1–4 kHz、8–16 kHz）+ 512 点滑动能量 |
| 诊断输出 | 10 Hz X 帧（`level, score, ber, mu, sd, flags, ...`） |

> 系统提供麦克风与线路两路输入。本实验使用线路输入，目的是让同一段素材可精确重复；算法本身与输入方式无关。

### 2.2 自变量：背景噪声

| 类型 | 构成 | 实测 BER 中位 |
|---|---|---|
| `white` | 白噪声，能量按带宽分布 | 0.78 |
| `hf` | 白噪声 + 8–16 kHz 带通噪声（功率占比 0.65） | 0.97 |

强度三档（RMS，相对满幅）：`quiet` 0.020 / `mid` 0.045 / `loud` 0.090。

### 2.3 异响信号（固定 RMS 0.060）

| 名称 | 构造 | 主要能量位置 |
|---|---|---|
| `squeak` | 13 kHz 单音 + 8 Hz 调幅 | 高频带 |
| `sweep` | 12→16 kHz 线性扫频 | 高频带 |
| `gear` | 250 Hz 冲击串 × 3 kHz 共振 | 低频带 |
| `impact` | 60 ms 间隔连串冲击 × 2.5 kHz 共振 | 低频带 / 宽带 |

由此得到约 **+9.5 / +2.5 / −3.5 dB** 三档信噪比。每条件 4 类 × 6 次 = **24 次**，六个条件共 **144 次**。

每个测试文件结构：`[60 s 噪声预热][异响 0.8 s + 噪声 1.7 s] × 24`。
预热段用于让系统重建基线（持续告警 30 s 触发重建 + 2 s 收敛），其最后 20 s 作为纯噪声段统计误报。

### 2.4 对比的四种判据

四种判据在**同一条 X 帧特征流**上离线评估，统一要求"连续 3 帧确认"（300 ms），保证口径一致：

| 代号 | 判据 | 说明 |
|---|---|---|
| **A** | `10·log10(E_L+E_H) > 40.7 dB` | 固定能量阈值，按"安静白噪声 +6 dB"标定 |
| **B** | `BER > 0.850` | 单侧固定 BER 阈值（对应"高频占比上升即异常"的原始设计） |
| **B2** | `BER > 0.850 或 BER < 0.650` | 双侧固定 BER 阈值（补一组，避免"你只是把单侧改成双侧"的质疑） |
| **C** | `score > χ²(2,0.001)` 或能量突增 | 本系统的动态基线 + 二维卡方判决 |

### 2.5 指标

- **POD（检出率）**：异常起点后 1.2 s 内出现确认告警的比例。
- **占空比**：纯噪声 20 s 窗口内处于"确认告警"状态的帧占比。
  **这是本实验最关键的指标** —— 一个恒为真的判据可以轻易拿到 100% 的 POD，但占空比会暴露它。

## 4. 结论

**结论一：两种固定阈值方案在真实背景下都会"常亮"，此时的检出率没有意义。**

- 固定能量阈值（A）在背景噪声升到中等强度后，占空比直接 **100%** —— 它把背景噪声本身当成了异常，POD 虽然显示 100%，但系统已经失去判别能力。
- 固定 BER 阈值（B / B2）在安静白噪声下不误报，但一旦环境高频成分升高（`hf` 条件），占空比 **100%** —— 判据恒为真，同样是失效。
- 单侧固定 BER（B）在安静白噪声下只有 **50%** 检出率：齿轮啮合与冲击这类异常表现为 BER **下降**，单侧判据根本看不到，必须靠双侧或对称的统计判决。

**结论二：多维判决在全部 6 种条件下占空比均为 0%，同时保持高检出率。**

C 组在 144 次试验中，纯噪声段一次都没有进入告警态（占空比 0.0%），
而 POD 在 4/6 个条件下 ≥ 95%，其余两档的下降有明确的物理原因（见结论三）。

**结论三：唯一的性能跌落发生在"高频背景噪声 + 低信噪比"，这是方法的物理边界。**

在 `loud_hf` 条件下 C 组 POD 降至 37.5%，且下降只发生在 `squeak`/`sweep` 这两类高频异常上；
`gear` 仍保持 6/6。原因很直接：当背景噪声本身占据 8–16 kHz 时，高频异响不再改变频带能量分布，
BER 这一维失去可分性。这不是实现缺陷，而是"频带能量比"类方法的固有边界。
对应的改进方向是增加时间结构维（峭度/包络周期性），而不是继续调阈值。

> 一句话总结：**固定阈值在一种背景下好看、换一种就失效；动态基线在六种背景下都不误报，代价是高频强噪声下的灵敏度下降。**

## 5. 局限与说明

1. **10 Hz 诊断帧 + 300 ms 确认对极短瞬态不公平。** 单次金属敲击的能量只持续 50–100 ms，
   落在两次采样之间就会被漏掉。板端实际判决在 50 Hz 上运行（120 ms 确认），
   单独测试中 6 次金属敲击全部捕获（见 `项目现状.md` §13.2）。
2. **异响为合成信号**，用于控制信噪比和可复现性，不等同于真实故障件。
3. **样本量有限**（每条件 24 次），统计置信区间较宽，趋势可信但绝对值不宜过度解读。
4. 背景噪声为平稳噪声，未覆盖非平稳场景（如人声、开关门）。

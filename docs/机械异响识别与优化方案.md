> 对象：Zynq-7010 双带能量监测系统（`项目现状.md` v1.0）
> 目的：回答两个问题 —— ① 怎么真正区分环境噪声和机械异响；② 现有实现怎么继续优化
> 日期：2026-11-02

> **实施状态（2026-11-02 晚）**：§3 的多维判决框架与 §4 的 P0 已落地并上板验证，

## 0. 结论先行

1. **现在做的不是"区分"，是"偏离报警"**。`BER > 阈值` 只回答"高频占比是否超过某个数"，回答不了"这是噪声还是机械故障"。两者在**谱形**和**时间结构**上是可分的，但当前系统只用了谱形的一个标量投影，时间结构维度（峭度）被摘掉了（见 `anomaly_detect.v` 第 98–101 行注释）。
2. **判据应该从"绝对阈值"升级为"统计显著性"**。BER 在纯白噪声下的理论值是 `8/(2.9+8)=0.734`，实测 0.753 —— 说明底噪确实是白的，也说明这个量的基线是**滤波器带宽决定的常数**，不是环境学出来的。用 `0.85` 去卡 `0.753`，只有约 3.5σ 余量（σ≈3%，见 §2.1），环境里一出现稳定的高频成分（风扇、气流、变频器）就整体抬升，判据失效。
3. **最值得做的三件事**（按投入产出）：
   - **P0（不改 RTL，1–2 天）**：持续跟踪基线 + 门控更新 + 多维 z-score + 手动重学 + 事件分级。
   - **P1（改 RTL 一次，1–2 周）**：数字自动增益 DAGC、4 子带、双窗口、修复峭度、门限寄存器化、中断。
   - **验证（最缺）**：现在只有"触发次数"，没有误报率 vs 检出率。答辩最容易被问倒的就是这里（§7）。
4. 一句话回答"怎么区分"：**噪声是平稳、宽带、高斯的；机械异响是冲击性、窄带、或循环平稳的。所以判据要看"多大、在哪、怎么变"三个维度，而不是只看音量。**

## 1. 噪声与异响到底差在哪

### 1.1 三个可判别维度

| 维度 | 物理量 | 环境噪声 | 机械异响 |
|---|---|---|---|
| **幅度** | 总能量、峰值 | 可以很大（风机、泵） | 早期磨损可以很小 |
| **谱形** | 子带能量比、谱斜率、谱集中度 | 形状固定、缓慢变化，通常是低频为主的平滑谱 | 出现新谱峰/共振带；高频陡增（摩擦、啸叫）；宽带爆开（冲击） |
| **时间结构** | 峭度、峰值因子、包络周期性、自相关 | 平稳、近似高斯，峭度≈3，自相关≈0 | 冲击（峭度 10–50）；周期性冲击（轴承/齿轮，包络谱有离散线）；循环平稳 |

**关键**：幅度维单独不可用（噪声也能很大，早期故障也很小）；谱形维可用但需要多个子带；**时间结构维才是机械故障的本质特征**，也是当前系统完全缺失的一维。

### 1.2 一张对照表（答辩可直接用）

| 输入 | 总能量 | 高频占比 | 峭度 | 谱形 | 包络周期性 | 判定 |
|---|---|---|---|---|---|---|
| 空调/风机 | 大 | 中 | ≈3 | 平滑、稳定 | 无 | 正常 |
| 人说话/脚步 | 中 | 中 | 3–6 | 变化但随机 | 无 | 正常（需负样本训练） |
| 金属摩擦/啸叫 | 中小 | **很高** | 3–6 | **窄带峰** | 可能有 | 摩擦类异常 |
| 单次冲击/敲击 | 突增 | 高 | **很高** | 宽带瞬时 | 无 | 冲击类异常 |
| 轴承早期故障 | 小（可能低于噪声） | 中高 | 中高 | 共振带 | **有，且与转速锁定** | 早期磨损（重点） |
| 齿轮打齿 | 中大 | 高 | 高 | 宽带+边带 | 有（啮合频率） | 齿类异常 |

### 1.3 为什么"音量"不能作为判据

现场同时存在：设备噪声大但正常、设备噪声小但已磨损、环境噪声突然变大（隔壁开机）。任何基于绝对能量或固定比值的判据，都只能在其标定环境下成立。**能跨环境工作的判据必须是对"自身基线"的统计偏离，而不是绝对量。**

## 2. 现有方案的定位与边界

### 2.1 BER 的物理意义（这是现有设计最大的亮点，也是最大的坑）

两条 FIR 的等效带宽约 2.9 kHz（1–4 kHz）与 8 kHz（8–16 kHz）。白噪声的带内能量正比于带宽，所以

```
BER_white = 8 / (2.9 + 8) = 0.734
```

实测静音底噪稳定在 **0.753**，与理论值吻合到 2.6% —— 这证明：① 底噪确实是白的；② 系统链路（PGA +18 dB、ADC、FIR）是自洽的。**这是可以写进答辩的硬证据。**

但同时说明：**BER 的基线不是环境给的，是滤波器带宽给的常数**。所谓"自适应基线"，学到的只是环境噪声相对白噪声的谱倾斜偏移量。

**估计方差**：512 点窗（10.7 ms）内，1–4 kHz 带的独立样本数约 `2BT ≈ 64`，8–16 kHz 带约 171，比值估计的标准差约 **3%（绝对）**。所以静音下 BER 在 `0.75 ± 0.06`（2σ）内跳动是统计必然，偶发 0.78–0.79 完全正常（对应 1.4σ）。

→ **0.85 的阈值只有约 3.5σ 余量。** 这不是"留了 12% 余量"，而是在赌噪声分布的尾部。

### 2.2 五个结构性风险

| # | 问题 | 位置 | 后果 |
|---|---|---|---|
| 1 | 固定余量赌噪声尾部 | `EV_THRESHOLD 780` / `0.85` | 环境一有稳定高频成分（风扇、气流）即失效 |
| 2 | 基线只学 10 s 且**永久冻结** | `helloworld.c:141` `if (adapt_done) return;` | 设备启停、昼夜班次、环境变化后失配；学习期若含异常则被污染 |
| 3 | 门限写死在 RTL | `anomaly_detect.v` `GATE=100000`、`den>=150000` | 轻冲击被挡（金属敲击 0 次触发即此因）；每次调参要重综合 |
| 4 | 单窗口打天下 | 512 点 EMA（10.7 ms） | 对稳态异响太短（估计抖），对冲击太长（被平均掉） |
| 5 | 单一特征 | BER 一维投影 | 丢掉了谱形其余信息；峭度被摘除，时间结构维完全缺失 |
| 6 | 滤波器阶数偏短 | `audio_energy.v` 31 阶 | 两带频域重叠，BER 判别力被削弱（见 §2.3） |

补充：`GATE=100000` 与 `den>=150000` 语义重叠且后者偏高；`CONFIRM_ON=3` 对应 3 ms 而注释写 8 ms；`thr=mean+2σ` 而日志打印 "3 sigma"。这些不一致答辩时会被抓。

### 2.3 滤波器阶数偏短（零成本、被低估的一项）

31 阶 @ 48 kHz，用 Kaiser 窗估算过渡带宽 `Δf ≈ (A−8)/(2.285·N) · fs/(2π)`：

```
A = 60 dB, N = 31   → Δf ≈ 5.6 kHz
A = 60 dB, N = 127  → Δf ≈ 1.4 kHz
```

低带只有 3 kHz 宽（1–4 kHz），过渡带 5.6 kHz 意味着**两个"带"在频域上大幅重叠**。实测 BER 基线 0.753 与理论带宽比 0.734 吻合，说明等效带宽尚可，但带间重叠会让两路能量高度相关，**BER 的判别力被削弱** —— 这可能是"底噪 BER 偶尔冲到 0.79"的另一个来源。

改成 127 阶几乎不花资源：现在 DSP 只用了 6/80，每个样本有 `50 MHz / 48 kHz = 1041` 个时钟周期可用。4 带 × 127 阶 = 508 次 MAC，用 8 个乘法器并行只需 64 拍。**一分钱不花，也不花资源。**

## 3. 目标框架：多维特征 + 统计显著性

把"阈值报警"换成"异常检测器"：

```
特征向量  x = [ BER, log2(E_total), kurt_log2, slope, CF, ρ_env ]
基线      μ_i, σ_i   （持续跟踪，门控更新）
异常分数  S = Σ_i ((x_i - μ_i)/σ_i)²        （对角马氏距离）
判决      S > χ²(k, α)  且持续 N 帧 → 分级告警
```

优点：① 多维联合，单一维度的环境波动不会直接触发；② 阈值有统计含义（χ² 分位数），可解释；③ 特征可增删，扩展性好；④ 正是"只有正常样本"场景下的标准异常检测做法（novelty detection）。

**门控更新**（解决基线漂移与污染）：

```
if (最近 5 s 无告警) and (所有 |x_i - μ_i| < 2.5σ_i):
    更新 μ_i, σ_i （EWMA，N≈3000 ≈ 60 s）
```

即：只在"确认平稳"时学习，异常样本永远进不了基线。

**事件分级**（替代二值 latched）：

| 级别 | 条件 | 展示 |
|---|---|---|
| L1 关注 | S > χ²(0.01) 持续 3 帧（60 ms） | 黄色 |
| L2 告警 | S > χ²(0.001) 持续 6 帧，或能量突增 | 橙色 + 提示音 |
| L3 严重 | L2 且峭度/CF 同时超限，或持续 > 1 s | 红色 + 弹窗 |

### 3.1 温声融合：让"多模态"名副其实

标题写的是"多模态"，但目前只有声音 + 温湿度两种物理量，答辩时容易被问"温湿度跟异响有什么关系"。零采购做不了振动模态，但可以用**趋势融合**把 SHT30 变成真正的第二判据：

| 现象 | 声学 | 温度 | 判读 |
|---|---|---|---|
| 正常 | 平稳 | 平稳 | 正常 |
| 环境升温（空调故障） | 平稳 | 上升 | 环境事件，非设备故障 |
| 轴承过热早期 | 高频占比缓升 + 峭度升高 | **缓慢单调上升** | 高置信度轴承磨损 |
| 短期冲击 | 能量突增 | 不变 | 冲击事件 |

规则（PS 侧，几行代码）：

```c
dT = T_now - T_baseline;            /* 基线同样用 §4.1 的门控 EWMA */
if (dT > 3.0 ℃ 持续 > 5 min && S > chi2_001)
    → L3："过热 + 声学异常，疑似轴承磨损"
```

好处：① 温度是慢变量，几乎不会被噪声误触发，能把声学的误报压下来；② 给出"过热"这个有物理意义的结论，而不只是"有异响"；③ 完全零成本。

## 4. P0：不改 RTL 的改造（PS + 上位机，1–2 天）

不改 PL、不重新综合，只改 `helloworld.c` 与 `server.py` / `app.js`。

### 4.1 基线持续跟踪 + 门控更新

替换 `adapt_feed()` 的一次性学习：

```c
/* 全部 Q8 定点，整数运算 */
static s32 mu[N], var[N];      /* 基线均值/方差 */
static u32 n_upd = 0;

void baseline_update(s32 x[N], int alarm_recent)
{
    int i, ok = 1;
    for (i = 0; i < N; i++)
        if (abs(x[i] - mu[i]) > 5 * var_isqrt(var[i]) / 2) ok = 0;  /* 2.5σ */

    if (alarm_recent || !ok) return;          /* 门控：异常样本不参与学习 */

    for (i = 0; i < N; i++) {
        s32 d = x[i] - mu[i];
        mu[i]  += d / 3000;                    /* τ ≈ 60 s @50 Hz */
        var[i] += (d * d / 3000 - var[i]) / 3000;
    }
}
```

### 4.2 鲁棒统计量替代 mean+2σ

维护 64 点环形缓冲，取**中位数 + MAD**：

```
σ_robust = 1.4826 × MAD
thr      = median + k × σ_robust      (k = 4)
```

抗污染、抗非高斯，且 64 点排序在 50 Hz 下开销可忽略。

### 4.3 三维 z-score（零 RTL 改动即可实现）

PS 现在就能拿到三个特征，无需改 PL：

| 特征 | 来源 |
|---|---|
| `BER` | `energy_ratio_permille()` |
| `log2(E_total)` | `energy_low + energy_high` 取 msb + 插值（已有 `energy_to_db10`） |
| `kurt_lvl` | `status[31:28]`（4 bit 近似 log2 峭度，已上板） |

```c
/* σ 下限保护：避免量化噪声导致除零/爆分 */
if (sigma < max(2 * mu / 100, 1)) sigma = max(2 * mu / 100, 1);

S = 0;
for (i = 0; i < 3; i++) { s32 z = (x[i] - mu[i]) * 256 / sigma; S += z * z; }
/* 3 自由度：χ²(0.01)=11.34, χ²(0.001)=16.27 */
```

`kurt_lvl` 在低电平时会被量化噪声抬高且抖动大 —— 用上面的 σ 下限即可压住，不需要摘掉。

### 4.4 分带噪声底跟踪 + 残差谱形（"把噪声减掉"）

这是最直接回答"怎么区分"的一步：**噪声是参考，不是敌人**。

```c
/* 每个子带维护一条"噪声底"：快降慢升（minimum statistics 的简化版） */
if (E_i < N_i) N_i += (E_i - N_i) / 8;        /* 下降快：跟住安静期 */
else           N_i += (E_i - N_i) / 4096;     /* 上升慢：不被异响带跑 */

/* 检测量：扣除噪声底之后的谱形 */
R_i = (E_i > N_i) ? (E_i - N_i) : 0;
resid_ratio = R_high / (R_low + R_high);      /* 分母过小时不判 */
```

安静时 `R` 接近 0，比值无意义 → 自然不报警；异响时 `R` 偏向异响所在频带。这比"直接拿 E 算比值"稳健得多，且为 P1 扩到 4 带后直接复用。

### 4.5 手动"重新学习"命令

新增 UART 命令帧 `C,1`（或复用 S 帧的命令位），PS 收到后清零 `mu/var` 重新学习。上位机加一个按钮。

价值：**基线必须在"设备正常运行时"学**。现在开机就学，如果开机时设备没转，学到的只是房间噪声，设备一转就全报警。手动触发把这个前提变成显式操作，演示时也好讲（"现在是正常状态，按一下学习"）。

### 4.6 事件分级上报

`E` 帧增加 `level` 字段；`T` 帧 `state` 从 0/1/2 扩为 0/1/2/3。上位机按级配色。

## 5. P1：改 RTL 的改造（PL，1–2 周）

资源余量极大（LUT 10.5%、FF 8.0%、DSP 7.5%、BRAM 0），可以放手加。

### 5.1 数字自动增益 DAGC（**优先级最高**）

现状：轻信号下 `|y| ≈ 40`，能量只有几位有效，峭度被量化噪声淹没（`anomaly_detect.v:98-101` 说得很准确）。

做法：在 I2S 接收后加一级桶形移位，按慢速 RMS 选 shift，把信号拉到约 −12 dBFS：

```
rms_slow ← EWMA(y²)              τ ≈ 0.5 s
shift    ← 使 rms_slow << (2*shift) 落在 [0.02, 0.1] 满幅
y_g      = y << shift            （上限 2~4 倍，防削顶）
```

成本：一个 4 bit 桶形移位 + 一个比较器链，几乎免费。

收益：① 峭度可用了；② 能量分辨率提高；③ **弱信号可检测 —— 直接对应"早期磨损"这个题目本身**；④ 门限不再依赖输入电平。

### 5.2 4 子带 + 谱斜率

现在 2 带（1–4 k、8–16 k）。扩到 4 带：`0.5–1 k / 1–4 k / 4–8 k / 8–16 k`。

成本：多 2 组 31 阶 FIR，时分复用 2 个乘法器 → 每样本 4×31 = 124 拍 @50 MHz = 2.5 µs < 20.8 µs（48 kHz），完全够；DSP 仍只需 2 个。

收益：谱形从 1 维变 3 维（相邻带比），可区分"低频轰鸣 / 中频摩擦 / 高频啸叫 / 宽带冲击"。

### 5.3 双窗口能量

```
短窗   128 点（2.7 ms）  → 抓冲击峰值、算 CF
长窗  2048 点（43 ms）  → 抓稳态异响，BER 估计标准差从 3% 降到 1.5%
```

成本：多一组 EMA（几个加法器）。收益：解决"单窗口打天下"。

### 5.4 修复峭度

按 `kurtosis_monitor.v` 现在的实现，低电平失效有三个原因，逐个修：

| 原因 | 修法 |
|---|---|
| 输入是**未滤波**原始样本，量化噪声主导 | 改用带通后的 `y_h`，且放在 DAGC 之后 |
| 512 点窗对 y⁴ 这种重尾统计量样本太少 | 加到 4096 点（85 ms） |
| 绝对门限 `KURT_K=15` 不适应电平 | 改为"相对自身基线的 z-score"，或 `kurt > 基线 × 3` |

再加一条 GATE：仅当 `den > 1e5` 时才输出 `kurt_hit`，低电平只观测不判定。

### 5.5 峰值因子 CF

```
CF = max|y| / rms        （512 点窗）
```

比峭度更简单、更抗量化，对冲击同样敏感。高斯噪声 CF ≈ 4，冲击 CF > 8。成本：一个比较器 + 一次除法（或乘法比较）。

### 5.6 参数寄存器化（**务必做**）

现在 `GATE`、`JUMP_RATIO`、`CONFIRM_ON/OFF`、`KURT_K` 全是编译期常量。改成 AXI-Lite 可写寄存器，PS 每帧根据基线下发。这样现场调参不用重新综合 —— 现在"金属敲击 0 次触发"这类问题，本质上就是被写死的 `150000` 挡住了。

建议寄存器表（偏移 + 语义）：

| 偏移 | 名称 | 说明 |
|---|---|---|
| 0x00 | THR_RATIO | 比值阈值（千分比） |
| 0x04 | GATE_ABS | 绝对能量门限 |
| 0x08 | GATE_JUMP | 突增门限 |
| 0x0C | CONFIRM_ON / OFF | 确认/解除帧数 |
| 0x10 | CTRL | enable / clear / irq_en |
| 0x14 | STATUS | 计数 / latched / above / kurt |
| 0x18–0x24 | E_BAND0..3 | 4 子带能量 |
| 0x28 | FEAT | CF / kurt_lvl / ρ_max |

顺带把两个 AXI GPIO（0x41200000、0x41210000）合并成一个自定义 AXI-Lite slave，一次读全，省 AXI 事务。

### 5.7 中断替代 50 Hz 轮询

AXI GPIO 打开 `C_INTERRUPT=1`，`event_irq` 接 PL→PS 中断，PS 侧配 GIC，ISR 里只打时间戳 + 置标志。

收益：事件上报延迟从最坏 20 ms 降到 < 100 µs。现在 PL 已锁存所以不丢事件，但实时性差，而且 `ev_count` 靠轮询比较，极端情况下同一帧可能漏判两次事件。

### 5.8 包络自相关（可选，但最能打）

**这是机械故障区别于环境噪声的本质特征：循环平稳性。** 轴承/齿轮的冲击按固定周期重复，包络谱上有离散线；环境噪声没有。

简化实现：

```
y_h → |y_h| → 低通(≈500 Hz) → 包络 e[n]，抽到 12 kHz
ρ(k) = Σ e[n]e[n-k] / Σ e[n]²,  k ∈ [8, 512]
ρ_max = max ρ(k)
```

成本：1024 点 × 504 lag ≈ 516k MAC，1 个 DSP @50 MHz = 10 ms，每 200 ms 算一次 → 占 5%。BRAM 用 1 个 BRAM18。

判读：`ρ_max > 0.3` 且峰值 lag 稳定 → 周期性冲击（轴承/齿轮），还能由 lag 反推冲击重复频率 → **故障定位**，正好补上 `项目现状.md` 里"包络谱/FFT 未做"的短板。

时间紧的话这一条可以放到最后，但它是最有"技术含量"的一条。

## 6. P2：系统与演示

### 6.1 串口已是瓶颈（加字段前必须先解决）

当前 T 帧约 60–70 字节，50 Hz → 约 30% 的 115200 带宽，且 `xil_printf` 是**阻塞**发送，每帧阻塞约 6 ms。再加 4 子带 + 峭度 + CF 会到 110 字节/帧 = 9.5 ms，占满半个帧周期。

三个选项（任选）：
- 波特率提到 **460800**（两端都支持，改一行）；
- 改**二进制帧**（省约 40%，且解析更快）；
- 降到 **25 Hz**（监测够用，图表仍流畅）。

推荐 460800 + 二进制，一步到位。

### 6.2 上位机加分类器

PC 侧用 Python 离线训练一个**一类模型**（只有正常样本，正合本场景）：

- 特征：4 子带 dB、3 个相邻带比、峭度、CF、ρ_max、温湿度
- 模型：GMM（每类一个）或 One-Class SVM / 对角马氏距离
- 在线：PS 只送特征，PC 分类并回显类别

答辩时给**混淆矩阵**，比"触发了 N 次"有说服力得多。

### 6.3 事件前后音频留证（加分项）

PL 维护 2 s 环形缓冲（16 kHz 抽采 → 64 KB，7010 的 BRAM 够），事件触发时把前后各 1 s 上传。演示时可以直接回放"报警那一刻的声音"，冲击力很强。

### 6.4 QSPI 固化

## 7. 实验验证方案（**目前最缺，答辩最容易被问倒**）

现有数据（静音 25 s 0 次、13 kHz 11 次）只能证明"能触发"，**不能证明"能区分"** —— 因为没有负样本，没有误报率，没有信噪比扫描。

### 7.0 样本集零成本构建

不需要采购任何素材：

- **正样本**：`numpy` / `scipy.signal` 合成。轴承故障 = 冲击串 × 结构共振（指数衰减正弦）+ 噪声；齿轮 = 啮合频率调制 + 边带；啸叫 = 窄带调频；冲击 = 单极脉冲经共振滤波。
- **负样本**：手机录空调三档、风扇、人声、键盘、关门、脚步；或直接用公开数据集（MIMII、DCASE）。
- **混合**：按目标 SNR 叠加，一个脚本生成全部测试集，可复现、可扩充。

这样 §7.3 的 SNR 扫描和 §7.4 的指标才有数据支撑，而且全程零成本。

### 7.1 负样本集：环境噪声（不应报警）

| 类别 | 时长 | 期望 |
|---|---|---|
| 空调/风扇 | 60 s × 3 档风速 | 0 报警 |
| 人说话/交谈 | 60 s | 0 报警 |
| 键盘/鼠标/关门/脚步 | 各 30 s | 0 报警 |
| 电机启停 | 各 5 次 | 允许 0–1 次（启停本身是瞬态，需说明） |
| 变频器/开关电源啸叫 | 60 s | 0 报警（这一类是难点，正好体现谱形判据的价值） |

**目标：连续 1 小时正常运行，误报 ≤ 1 次。**

### 7.2 正样本集：异响（应报警）

| 类别 | 次数 | 备注 |
|---|---|---|
| 金属摩擦/刮擦 | 30 | 稳态类 |
| 高频啸叫（12–16 kHz） | 30 | 已有素材 |
| 齿轮打齿 | 30 | 已有素材 |
| 金属冲击 | 30 | 需提高素材电平（见 `项目现状.md` §6.2） |
| 轴承早期（录音或实测） | 20 | **重点**，对应题目 |

### 7.3 信噪比扫描（核心实验）

把异响按 `-6 / -12 / -18 / -24 dB` 混入环境噪声，每个 SNR 重复 30 次，统计检出率。画出 **POD vs SNR** 曲线。这是"区分能力"的定量证明，也是答辩最有说服力的一张图。

### 7.4 指标

| 指标 | 定义 | 目标 |
|---|---|---|
| 检出率 POD | 正样本报警数 / 总数 | ≥ 95%（SNR ≥ -12 dB） |
| 误报率 FAR | 负样本报警数 / 小时 | ≤ 1 /h |
| 检测延迟 | 异响起始 → 上报 | < 100 ms |
| 最低可检 SNR | POD = 90% 对应 SNR | ≤ -12 dB |
| AUC | 二分类 ROC 面积 | ≥ 0.95 |

### 7.5 长时稳定性

连续 4 h，记录误报/漏报、PS 温度、SHT30 漂移、串口丢帧。顺便验证 §2.1 的推断：**2σ 阈值在小时尺度上大概率会误报** —— 这正好成为升级多维判据的实测依据，讲起来非常有说服力（"我们先测出问题，再改架构"）。

## 8. 答辩话术

**现在的答法**（`项目现状.md` §10）会被追问"环境变了怎么办""噪声本身波动大怎么办""微弱但周期性的冲击能量不大你怎么抓"。

**替换为三层回答**：

> **第一层，幅度**：我们不比绝对音量，比"偏离自身基线多少"。基线持续跟踪，只在设备稳定运行时更新，所以安静机房和嘈杂车间都能工作。
>
> **第二层，谱形**：白噪声的频带能量比由滤波器带宽决定，理论值 0.734，我们实测底噪 0.753 —— 说明判据有物理依据。异响会改变谱形：摩擦和啸叫让高频带陡增且谱峰变窄，冲击让全带瞬时爆开。我们用多子带能量比和谱斜率来描述这个形状，而不是一个数。
>
> **第三层，时间结构**：这是机械故障和环境噪声的本质区别 —— **噪声是平稳高斯的，机械异响是冲击性、周期性的**。我们用峭度和峰值因子抓冲击，用包络自相关抓周期性冲击。轴承早期故障的能量可能低于环境噪声，但它的冲击按固定周期重复，包络谱上有离散线，这个特征噪声没有。
>
> **所以我们的判据是三维联合的统计检验，不是单阈值。**

再补一句"噪声是参考不是敌人"：我们用分带噪声底跟踪把稳态噪声减掉，剩下的残差谱形才参与判定 —— 这相当于一个廉价的谱减。

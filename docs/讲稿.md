## 一、三分钟版（正式介绍）

### 0:00–0:15　开场

这是我们做的**工业机械异响与环境监测系统**。

它解决的问题是：车间里的电机、风机、泵，早期磨损的声音往往很轻，又混在环境噪声里，人耳听不出来；等能听出来，往往已经晚了。

### 0:15–1:00　架构

整套系统跑在一块 **Zynq-7010** 上。Zynq 的特点是把 FPGA 和 ARM 做在一颗芯片里。

我们让 FPGA 负责“听”：音频进来之后做两件事——一是把声音分成 **1–4 千赫**和 **8–16 千赫**两个频带，二是算每个频带的能量，再算高频能量占的比例。

ARM 负责“判断”：它完全不碰原始音频，只看这些特征。

这样分工的好处很直接：一个采样点 20.8 微秒来一次，FPGA 只用了 **32 个时钟**，也就是 **3%** 的时间预算，剩下 97% 是空的。

### 1:00–1:45　判据

判断这块我们没有用固定阈值。固定阈值的问题是换个环境就失效——安静的时候能用，一到嘈杂车间就一直在报警。

我们改成**先学习环境**：开机十秒，系统记住当前背景的频带能量比是多少、波动有多大，之后只看“**偏离自己基线多少个标准差**”。这个偏离量合成一个卡方分数，超过阈值才报。

另外加了一条针对生活噪音的：**说话声的能量集中在 4 千赫以下**，会让高频占比掉到接近 0。我们要求它**持续低于基线 440 毫秒以上**，才判为语音干扰，不报警。

### 1:45–2:20　证据

这套判据我们做了 **144 次对比实验**：两种背景噪声、三档强度、四类异响，每组六次。

结果很明确：固定能量阈值和固定频带比阈值，在部分噪声条件下**告警占空比是 100%**——判据恒为真，彻底失效；我们的动态基线判决，**六种条件下占空比都是 0**，同时大部分条件下检出率在 95% 以上。

### 2:20–2:40　边界（要主动说）

也有做不到的，我说清楚：

第一，异常上报现在是 **50 赫兹轮询**，延迟 20 毫秒，**中断还没接**；
第二，**单次冲击**——比如关门、脚步——和机械冲击在时域上是一回事，现在分不开；
第三，异常前后的**音频回溯还没做**。

### 2:40–3:00　收尾

所以我们现在的定位是：**把声学特征提取下沉到 FPGA，把统计判决留给 ARM**，用一套能自适应的判据，在低成本、不用外接显示屏的条件下，把机械异响从环境噪声里挑出来。

## 二、一分钟版（时间被压缩时）

这是一个**工业机械异响与环境监测系统**，跑在 Zynq-7010 上。

FPGA 负责听：把声音分成 1–4 千赫和 8–16 千赫两个频带，算能量、算高频占比；一个采样点只用 32 个时钟，占 3% 的时间预算。ARM 负责判断：不碰原始音频，只做统计判决。

判据不用固定阈值，而是开机学习环境、之后只看**偏离自己的基线多少个标准差**；说话声因为能量集中在低频，被判为干扰、不报警。

我们做了 144 次抗噪声对比：固定阈值在部分噪声下告警占空比 100%、等于失效；我们的方案六种条件都是 0。

没做的也说清楚：中断没接、单次冲击分不开、音频回溯没做。

## 四、可能被问到的问题

| 问题 | 怎么答 |
|---|---|
| 为什么用 Zynq 不用 MCU？ | 一个样本 20.8 微秒来一次，FPGA 只用 32 个时钟；MCU 用软件依次做滤波、能量、判决，很难保证确定性。 |
| 为什么不用固定阈值？ | 试过。固定阈值在安静环境好用，噪声一升就恒为真。我们有 144 次实验数据证明。 |
| 能区分生活噪音吗？ | 说话、音乐能挡（BER 持续低于基线 440 毫秒）；关门、脚步挡不住，因为和机械冲击同构。 |
| 中断做了吗？ | 没做。现在是 50 赫兹轮询，延迟 20 毫秒；判定和锁存在 FPGA 完成，轮询只影响报得多快，不影响会不会漏。 |
| 为什么演示用线路输入？ | 系统有麦克风和线路两路输入。演示用线路是为了信号可重复——同一段素材每次播放一致，便于对比；现场部署直接用麦克风。 |
| 端到端延迟多少？ | 要拆开说：FIR 群延迟 0.31 毫秒、特征窗 10.7 毫秒、判决 3 毫秒、轮询 20 毫秒。 |
| 和云端方案比？ | 数据不出本地、不用联网、成本低；缺点是只能做单机监测。 |
| 峭度用了吗？ | 模块在 FPGA 里实现了，但输出还没接进判决链路，目前时间结构维靠能量突增顶着。 |

## 五、不要说的话（会被翻代码）

- ❌“通过中断通知 ARM” —— 中断没做
- ❌“三频带 / 多频带” —— 现在是两个频带
- ❌“可以回溯异常前后的音频” —— 没做
- ❌“能区分所有生活噪音” —— 只能挡语音类
- ❌“自定义 AXI 从机” —— 用的是 AXI GPIO
- ❌“峭度参与判决” —— 输出还没接通
